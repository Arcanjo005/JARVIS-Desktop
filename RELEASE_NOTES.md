# JARVIS Desktop 1.0

- Aplicativo Windows standalone: o usuário final não precisa instalar Python, pip ou Git.
- Configuração guiada da própria API key do Gemini.
- Chave protegida por Windows DPAPI e mantida fora do pacote de atualização.
- Atualizações via GitHub Releases com botão dentro do JARVIS.
- Verificação SHA-256 antes de executar qualquer instalador baixado.
- Memória, preferências, perfis de voz e dados locais preservados entre atualizações.
